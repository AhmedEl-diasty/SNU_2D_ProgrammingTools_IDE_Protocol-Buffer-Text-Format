## Features

- **User-Friendly Interface**: The IDE offers an intuitive layout, making it easy to navigate and write code.
- **Syntax Highlighting**: Enjoy clear visibility of your code with syntax highlighting for Protocol Buffer Text Format.
- **Error Detection**: Get real-time feedback on errors to streamline your coding process.
- **Customizable Themes**: Choose from various themes to suit your coding style.
- **Built-in Documentation**: Access documentation directly within the IDE for quick reference.

## Installation

To install the IDE, follow these steps:

1. **Clone the Repository**: Use the following command to clone the repository:
   ```bash
   git clone https://github.com/AhmedEl-diasty/SNU_2D_ProgrammingTools_IDE_Protocol-Buffer-Text-Format.git
   ```

2. **Navigate to the Directory**:
   ```bash
   cd SNU_2D_ProgrammingTools_IDE_Protocol-Buffer-Text-Format
   ```

3. **Install Dependencies**: Make sure to install all required dependencies. You can do this using your package manager. For example:
   ```bash
   npm install
   ```

4. **Run the IDE**: Start the IDE with the following command:
   ```bash
   npm start
   ```

For the latest releases, visit the [Releases section](https://github.com/AhmedEl-diasty/SNU_2D_ProgrammingTools_IDE_Protocol-Buffer-Text-Format/releases). Download the necessary files and execute them to get started.

## Usage

Once the IDE is up and running, you can start creating your projects. Here’s how to use the key features:

### Creating a New Project

1. **Open the IDE**.
2. **Select "New Project"** from the file menu.
3. **Choose a Location**: Specify where you want to save your project.
4. **Name Your Project**: Enter a suitable name for your project.

### Writing Code

- Open a new file and select the Protocol Buffer Text Format from the language options.
- Start writing your code. The IDE will provide syntax highlighting and error detection as you type.

### Saving Your Work

- Click on **File** > **Save** or use the shortcut `Ctrl + S` to save your progress.

### Accessing Documentation

- Use the built-in documentation feature to look up functions and syntax. This can be accessed from the help menu.
